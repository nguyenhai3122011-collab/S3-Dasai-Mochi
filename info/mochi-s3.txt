# 🍡 MOCHI S3 — Dasai Mochi Robot cho ESP32-S3

> Firmware **Mochi S3** là một robot mặt cảm xúc tự chạy cho board **ESP32-S3**, lấy cảm hứng từ
> [Dasai Mochi](https://dasai.com.au/pages/mochi3) — màn hình OLED 128×64/128×32, 17 biểu cảm được
> vẽ bằng thuật toán (không dùng ảnh bitmap), tự chớp mắt, tự nhìn quanh và tự đổi biểu cảm.

---

## ⚡ Tính năng

- **17 biểu cảm** vẽ realtime: Idle, Happy, Love, Angry, Sad, Sleepy, Surprise, Thinking,
  Dizzy, Wink, Laugh, Talking, Cool, Cry, Curious, Excited, Loading.
- **Chớp mắt** tự nhiên + **nhìn quanh** khi rảnh rỗi (mắt di chuyển theo đường cong mượt).
- **Tự động biểu cảm** (Auto mode): Mochi tự kể câu chuyện của nó, nghỉ ngơi rồi lại chào hỏi.
- **Điều khiển bằng nút / cảm ứng**: short press đổi biểu cảm, long press bật/tắt Auto mode.
- **Jingle** (nếu có loa piezo): mỗi biểu cảm có một nốt nhạc riêng.
- **Không cần thư viện ngoài**: driver SSD1306/SH1106 tự viết, chỉ dùng `Wire` của Arduino.
- **Siêu nhẹ**: firmware ~ 200 KB, chạy mượt ở 30 FPS trên ESP32-S3.

## 🔌 Cấu hình phần cứng

| Thành phần | Giao tiếp | Ghi chú |
| --- | --- | --- |
| ESP32-S3 (XIAO / SuperMini / DevKitC-1) | — | Não của robot |
| OLED SSD1306 128×64 hoặc 128×32 | I2C | Địa chỉ 0x3C (tự dò 0x3D) |
| OLED SH1106 128×64 | I2C | Dùng bản riêng, offset cột +2 |
| Nút nhấn (nếu có) | GPIO, kéo lên | Short = đổi mặt, Long = bật/tắt auto |
| Cảm ứng điện dung (tuỳ chọn) | GPIO1–GPIO14 | Chạm để đổi biểu cảm |
| Loa piezo (tuỳ chọn) | GPIO + tone() | Bật bằng `MOCHI_SOUND_ENABLE` |

### Sơ đồ chân mặc định

| Chức năng | GPIO | Ghi chú |
| --- | --- | --- |
| I2C SDA | 8 | Mặc định của ESP32-S3 & XIAO |
| I2C SCL | 9 | Mặc định của ESP32-S3 & XIAO |
| Nút nhấn | 0 | INPUT_PULLUP, xuống GND |
| Cảm ứng | 1 | XIAO ESP32-S3 không có nút nhấn |
| Loa | 6 | SuperMini / DevKitC-1 |

## 🔧 Cách nạp firmware

1. **Cắm cáp USB-C** vào Mochi (nếu không thấy cổng COM: giữ nút `BOOT` rồi cắm lại cáp).
2. Bấm **“Kết nối cổng COM”** và chọn đúng cổng serial.
3. Chọn **phiên bản firmware** ở bước 2 (xem bảng phía trên).
4. Bấm **“NẠP FIRMWARE MOCHI S3 (FLASH)”**, đợi tới 100%.
5. Bấm **“Reset Chip”** → Mochi chớp mắt chào bạn. 👋

### Nạp bằng `esptool.py` (không dùng trình duyệt)

```bash
esptool.py --chip esp32s3 --port /dev/ttyUSB0 --baud 921600 write_flash \
  0x0    mochi-devkit-64.bootloader.bin \
  0x8000 mochi-devkit-64.partitions.bin \
  0x10000 mochi-devkit-64.bin
```

Hoặc dùng file **merged** (đã gộp sẵn bootloader + partition + app):

```bash
esptool.py --chip esp32s3 --port /dev/ttyUSB0 --baud 921600 \
  write_flash 0x0 mochi-devkit-64-merged.bin
```

## 🛠 Tự build lại firmware

```bash
cd firmware-src
pio run -e mochi_devkit_64        # build cho SuperMini / DevKitC-1 128x64
pio run -e mochi_xiao_64          # build cho XIAO ESP32-S3 128x64
pio run                          # build tất cả
```

Tuỳ chỉnh trong `firmware-src/src/config.h`:

```cpp
#define MOCHI_SCREEN_W     128   // bề rộng màn hình
#define MOCHI_SCREEN_H     64    // chiều cao màn hình (32 hoặc 64)
#define MOCHI_OLED_OFFSET  0     // SH1106 = 2, SSD1306 = 0
#define MOCHI_OLED_SDA     8     // chân I2C SDA
#define MOCHI_OLED_SCL     9     // chân I2C SCL
#define MOCHI_BUTTON_PIN   0     // -1 để tắt
#define MOCHI_TOUCH_PIN    -1    // -1 để tắt
#define MOCHI_BUZZER_PIN   -1    // -1 để tắt
#define MOCHI_SOUND_ENABLE 0     // 1 để bật jingle
```
